# Демо-сайт кондитерской

Статичный сайт без сборки и без сервера приложений: HTML, CSS и JavaScript.
Это **демонстрация**: все товары, цены и контакты — условные примеры, о чём
сообщает плашка над шапкой и строка в подвале.

## Запуск

```bash
python3 -m http.server 4175
```

Затем откройте <http://localhost:4175>. Лучше через сервер, а не двойным кликом
по `index.html`: ссылки на стили и скрипты содержат `?v=…`, и при открытии
с диска (`file://`) некоторые браузеры их не находят.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: плашка демо, шапка, вкладки и фильтры, герой, каталог, «Как заказать», доставка, «Как нас найти», подвал, модалка товара, панель фильтров для телефона, корзина |
| `css/styles.css` | стили сайта; темы на CSS-переменных (`--bg-dark` / `--bg-light`, `--text-dark` / `--text-light` и т. д.) |
| `css/assistant.css` | плавающие кнопки, панель чата, веер соцсетей, облачко-подсказка |
| `css/cart.css` | корзина, тост «Добавлено», мобильная строка и панель фильтров |
| `js/data.js` | телефон владельца `OWNER_PHONE`, категории, SVG-иконки плейсхолдеров, каталог `PRODUCTS` |
| `js/app.js` | тема, фильтры и сортировка, сетка 2/3/4, 3D-наклон, модалка с выбором веса; отдаёт API `window.MK` |
| `js/cart.js` | корзина: счётчик, полёт торта в иконку, панель с формой; отдаёт `window.MKCart` |
| `js/assistant.js` | ИИ-помощник и веер соцсетей; пользуется `window.MK` |

Скрипты подключаются в порядке `data.js` → `app.js` → `cart.js` → `assistant.js`.

## Что заполнить владельцу

Сейчас на этих местах стоят заглушки — ничего правдоподобного не выдумано:

- **Телефон** — одна константа `OWNER_PHONE` в начале `js/data.js`. Пока в номере
  есть «_», кнопка «Позвонить» не звонит, а сообщает, что номер не указан;
  после замены номер появится в шапке и подвале.
- **Контакты** — подвал в `index.html`: e-mail, часы работы `__:__ — __:__`,
  адрес `г. ______, ул. ______`.
- **Адрес и карта** — блок «Как нас найти» (`#find`): серая заглушка 16:9,
  кнопки «Построить маршрут» и «Самовывоз» отключены. Карту подключать после
  того, как появится реальный адрес.
- **Доставка, оплата, хранение** — секция `#delivery`: поля `______`.
- **Состав и аллергены** — в каталоге их нет намеренно; в модалке стоит
  «Состав заполняется владельцем». Если добавлять — только реальные данные.
- **Соцсети** — ссылки веера пока `#`, по клику показывается тост «ссылка не
  настроена». Кнопки — в фирменных цветах сетей, глифы нарисованы вручную.
- **Плашку демо** убрать, когда данные станут настоящими: `.demobar` в
  `index.html` и строка `.footer__note`.

## Каталог

Товар — объект в `PRODUCTS` (`js/data.js`):

| Поле | Значение |
|---|---|
| `id`, `name`, `cat` | идентификатор, название, категория из `CATEGORIES` |
| `icon`, `c1`, `c2` | ключ иконки из `ICONS` и два цвета — из них рисуется плейсхолдер вместо фото |
| `perKg` | цена за кг — нужна для расчёта, на сайте не показывается |
| `minWeight` | минимальный вес; на карточке — «от» цены и веса за этот вес |
| `weights` | необязательно: свой набор весов (бенто, наборы капкейков) |
| `tiers` | число ярусов; в модалке показывается только у свадебных и многоярусных |
| `hit` | отметка «хит»; влияет на сортировку «сначала популярные» |
| `flavors` | теги вкуса для помощника: `шоколад`, `фрукты`, `ягоды`, `сливки`, `не сладко` (не состав — только профиль вкуса) |
| `desc`, `decor` | описание и декор — без перечисления ингредиентов |

Торт делается под заказ на нужный вес, фиксированной цены у него нет:
цена = `perKg × выбранный вес`. В модалке вес выбирается кнопками
1 · 1,5 · 2 · 2,5 · 3 · 4 кг (только не меньше `minWeight`; у свадебных —
от 3 до 10 кг). Поле «Гостей» лишь подсвечивает подходящий вес — выбирает человек.

Вес по числу гостей считает одна функция `weightForGuests()` в `app.js`:
180 г на человека, ближайший вес из кнопок торта. Её используют и подсказка
в модалке, и помощник — поэтому вес и цена в подборке совпадают с карточкой.

## Фильтры

- Вкладки категорий и цена работают вместе. Ценовые диапазоны не пересекаются:
  верхняя граница входит в диапазон, нижняя — нет (торт ровно за 6 000 ₽
  попадает в «3 000 – 6 000 ₽»).
- Категории, в которых при выбранной цене нет тортов, неактивны.
- Заголовок каталога следует за фильтром: «Детские торты до 3 000 ₽».
- Панель фильтров прилипает под шапкой только внутри каталога.
- Смена фильтра не двигает страницу. Если в глубине каталога после фильтра
  не осталось видимых карточек — страница плавно подводит к началу результатов,
  панель при этом остаётся на месте.
- На телефоне вместо рядов — кнопка «Фильтры (N)» с числом активных; она
  открывает панель снизу с категориями, ценой и сортировкой.
- Сортировка: сначала популярные, по возрастанию и по убыванию цены.
- Перестроение сетки — FLIP-анимация; смена колонок — View Transitions.

## ИИ-помощник

Работает **локально, без API и без сети** — это сценарий на JavaScript,
а не языковая модель. Порядок такой: гости → вкусы → бюджет (необязательно),
потом 2–3 карточки с одной строкой «почему этот». Клик по карточке открывает
обычную модалку товара.

- **Гости.** До 7 — один торт; 8–15 — один побольше; 16–30 — предлагает два
  разных и честно говорит, дороже ли это; больше 30 — несколько тортов или
  многоярусный, на выбор.
- **Бюджет — на общую сумму.** Итог пишется явно: `Два торта: A + B = C`.
  Если не влезает — подбирает вариант поменьше; если мал даже он — говорит прямо.
- **Распознаёт текст:** число привязывается к слову рядом — «торта», «гостей»,
  «бюджет», «₽». Понимает «5к», «тысяч пять», «полторы тысячи», «в пределах
  3-4 тысяч». Число больше 500 — бюджет, одно голое число — гости. Факты берёт
  из любого сообщения и подтверждает одной строкой «Понял: …». Если чисел
  несколько и не все понятны — не угадывает, а переспрашивает кнопками.
- **Названное число тортов не оспаривает** — при явном несоответствии гостям
  переспрашивает один раз и принимает ответ.
- **Обоснования — только из данных торта** (`flavors`, `desc`, вес); если торт
  тяжелее нужного, так и говорит.
- **Не делает:** не торопит, не выдумывает скидки, состав, сроки и контакты,
  не поднимает бюджет за клиента. На вопросы про адрес, телефон и доставку
  отвечает, что это демо-сайт.

## Что хранится в браузере

| Ключ `localStorage` | Что |
|---|---|
| `mk-theme` | тема: `dark` (по умолчанию) или `light` |
| `mk-filters` | категория и сортировка; цена не сохраняется — при новом заходе «Любая» |
| `mk-chat-v3` | история и шаг диалога с помощником; сбрасывается кнопкой «Начать заново» |
| `mk-cart` | корзина: торт, вес, количество |
| `mk-ai-hint` | облачко «Не знаете, какой торт выбрать?» уже показывали |
| `mk-ai-opened` | помощника открывали — кольцо вокруг кнопки больше не пульсирует |

## Корзина

Иконка в шапке (на телефоне — в строке фильтров) со счётчиком. «В корзину»
в модалке: торт летит по дуге в иконку, счётчик подпрыгивает, снизу тост
«Добавлено» с кнопками «В корзину» и «Продолжить». «Оформить заказ» в модалке
сразу открывает корзину. В корзине — позиции с весом, ценой и количеством,
общий вес и сумма, самовывоз или доставка (адрес спрашивается только при
доставке), дата и время, имя и телефон. Заказ **никуда не отправляется** —
показывается тост «Это демо-сайт, заявка не отправлена».

## Анимации и доступность

- Тема меняется круговым раскрытием от переключателя (View Transitions API);
  без его поддержки — плавный переход цветов за 300 мс.
- При `prefers-reduced-motion` отключаются все анимации, включая смену темы
  и потоковую печать помощника.
- Кнопки и чат работают с клавиатуры: Tab, Enter, Esc; у кнопок есть `aria-label`.

## Остаток от предыдущей версии: автозапуск Ollama

Старая версия помощника работала через Ollama, и для неё в macOS ставился
LaunchAgent, который при входе в систему выставляет переменную `OLLAMA_ORIGINS`.
Текущему сайту он **не нужен**. Если он у вас остался, проверить:

```bash
ls ~/Library/LaunchAgents/*ollama-origins.plist
```

Выгрузить и удалить:

```bash
for f in ~/Library/LaunchAgents/*ollama-origins.plist; do launchctl bootout gui/$(id -u)/"$(basename "$f" .plist)"; rm "$f"; done
```

Сбросить переменную до перезагрузки:

```bash
launchctl unsetenv OLLAMA_ORIGINS
```
